How to check a figure yourself

  1. Each run card links Claude Code's own output (claude.json). Its total_cost_usd and modelUsage are what Claude Code printed at the end of the session; the benchmark only saved them. They are Claude Code's computed cost, not a bill: the billed cost is in the provider's billing console.
  2. Difference = Claude Code computed − plugin estimate. It mixes requests the plugin does not see with estimation error, so it is not explained by cause; zero means the totals are consistent, not that each request was estimated right.
  3. In the run folder, sha256sum -c evidence.sha256 confirms no file changed since the run, and sha256sum evidence.sha256 prints the data hash shown here and in every screenshot of that run.
  4. node packages/cli/dist/cli.js bench verify benchmarks/results/<run> recomputes every figure from the raw files.
